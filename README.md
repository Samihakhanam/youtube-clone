The goal of this project is to replicate the YouTube homepage UI using only HTML and CSS, without any frameworks or JavaScript.
It helps in understanding real-world UI layouts, responsiveness, and clean CSS structuring.

UI Components Breakdown

1 Header
* Fixed navigation bar
* Search input with tooltip
* Voice search icon
* Notifications badge

2 Sidebar
* Fixed vertical navigation
* Icon + text layout
* Hidden automatically on mobile screens

3 Main Content
* Video thumbnail cards
* Channel profile images
* Title, author, views, and upload time
* Video duration overlay
